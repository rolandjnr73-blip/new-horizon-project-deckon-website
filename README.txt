DECKON TECHNOLOGIES LIMITED — LOCAL WEBSITE PROJECT

HOW TO RUN
1. Extract this entire folder (do not move index.html away from the other files).
2. Open the folder.
3. Double-click index.html, or right-click it and choose Open with > Chrome/Edge/Firefox.
4. Keep the images folder beside index.html. The page uses relative paths such as images/image-2.jpg.

FILES
- index.html: page content and structure
- style.css: visual design, layout and responsive styles
- script.js: mobile navigation and feedback form actions
- images/: logo and product images used by the page

NOTES
- The Google Fonts stylesheet is optional; if the computer has no internet, the page uses system-font fallbacks.
- Phone, email, address and map details should be confirmed with Deckon before submission/publication.
- The feedback form opens WhatsApp or the visitor's email app. It does not store submissions or send weekly reports automatically; that needs a backend service.
- Internet is needed for WhatsApp, email links, Google Maps and Google Fonts. The main layout and local images work offline.
